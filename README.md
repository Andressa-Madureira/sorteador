# Sorteador🎲 

Este projeto demonstra uma implementação simples e eficiente de um sorteador de números usando HTML e JavaScript. Desenvolvido após as aulas do curso DevClub, é uma ótima solução para entender como manipular entradas de usuário e gerar resultados aleatórios de forma interativa.

🛠️ Tecnologias Utilizadas
<ul>
  <li>HTML: Estrutura e layout da página</li>
  <li>JavaScript: Lógica de sorteio e validação de entradas</li>
</ul>

🚀 Funcionalidades
<ul>
  <li>Validação de Intervalo: Garante que o valor mínimo seja sempre menor que o máximo</li>
  <li>Geração Aleatória: Sorteia um número dentro do intervalo especificado e o exibe em um alerta</li>
</ul>

📂 Estrutura
<ul>
  <li>HTML: Campos de entrada de número</li>
  <li>JavaScript: Lógica do sorteio, validação e exibição do resultado</li>
</ul>

Este projeto é uma excelente forma de aprender como criar interações simples com o DOM, manipulação de inputs, e como realizar validações no JavaScript de forma eficaz. Ideal para iniciantes e para quem quer demonstrar habilidades de programação em projetos práticos e diretos.
